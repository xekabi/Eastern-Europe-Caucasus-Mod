# Как получить Forge .jar (Minecraft Java 1.20.1)

Важное: в этой поставке **нет проверенного установочного JAR**. Это проект для реальной
сборки; автор проекта не мог получить зависимости ForgeGradle из своей среды.
Работоспособность исходников в игре не подтверждена. Если сборка выдаёт ошибку,
не следует считать полученный файл игровым релизом.

## Способ 1: сборка на GitHub (без установки Java на свой ПК)
1. Создай пустой репозиторий на GitHub.
2. Распакуй ZIP проекта и загрузи в репозиторий **содержимое** папки, включая
   скрытую папку `.github` (сам ZIP-файл загружать недостаточно).
3. Открой вкладку **Actions** → **Build Forge 1.20.1 mod** → **Run workflow**.
4. При успешном завершении внизу страницы запуска появится артефакт
   `EAC16-Forge-1.20.1` с файлом `eac16-0.1.0.jar`.
5. Распакуй артефакт; перенеси только `.jar` в папку `mods` установки
   Minecraft **1.20.1 с Forge 47.x** (не Fabric / NeoForge).

Сборка пройдёт только при отсутствии ошибок компиляции и при доступности Maven Forge.

## Способ 2: на компьютере
- Требуется JDK 17 и интернет.
- Windows: открой `build-windows.bat`.
- Linux/macOS: `./build-linux-macos.sh`.
- При успехе получишь `build/libs/eac16-0.1.0.jar`.

Важно: первое скачивание Gradle и зависимостей может быть объёмным.
После получения JAR его всё равно нужно протестировать в Minecraft.

## Ожидаемое игровое поведение
- Напитки: ПКМ в воздух — пить, ПКМ по верхней поверхности — поставить бутылку.
- Бутылка: ПКМ пустой рукой — забрать.
- Стойка: ПКМ бутылкой — положить, ПКМ пустой рукой — забрать.
- Бочка/квеври: ПКМ суслом — добавить; после 2400 тиков ПКМ пустой бутылкой — разлить.
- Фитильное оружие: железная пуля + порох; удерживать ПКМ — зарядить,
  затем ПКМ — стрелять.
- Покачивание камеры уменьшается настройкой `cameraSway` в клиентском конфиге.
