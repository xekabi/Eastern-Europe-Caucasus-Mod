# Eastern Europe & Caucasus Mod (1500–1550)

Experimental Minecraft Java **1.20.1 / Forge 47.x** historical mod.

Content: Georgian equipment, early matchlock firearms, regional wines/mead/beer, wine barrels, qvevri, wine racks, placeable bottles, and custom intoxication mechanics.

**Status:** experimental prototype. A successful Gradle build does **not** replace an in-game playtest. Use GitHub Actions → Build Forge 1.20.1 mod → Artifacts to download the JAR after a successful run.

See [README_RU.md](README_RU.md) and [HOW_TO_GET_JAR_RU.md](HOW_TO_GET_JAR_RU.md).
