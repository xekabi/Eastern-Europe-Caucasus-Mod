# Eastern Europe & Caucasus: 1500–1550 — Forge 1.20.1

**Статус: исходный код игрового прототипа v0.1.0, НЕ собран и НЕ проверен в Minecraft.** В текущей среде нельзя скачать ForgeGradle/Maven. Для получения `.jar` предусмотрена автоматическая сборка в GitHub Actions или локально; смотри `HOW_TO_GET_JAR_RU.md`. Не называй этот пакет готовым проверенным модом без успешной сборки и игрового теста.

## Что реализовано на Java
- Регистрация 4 блоков (стойка, бочка, квеври, бутылка-объект), 23 основных предметов и 2 служебных предметов, отдельная творческая вкладка.
- 5 элементов брони с собственным материалом и двумя 64×32 атласами; щит и наруч (наруч — пока обычный предмет).
- 3 ранних фитильных ружья: анимация перезарядки, отдельные железные пули + порох, NBT-флаг заряда, урон по линии прицеливания, дым, звук, разброс, время перезарядки.
- 9 исторически ориентированных напитков; 10-й «неподтверждённый виноградный дистиллят» сознательно исключён из реестра, хотя текстура в ресурсах сохранена.
- Опьянение на стороне сервера, затухание раз в 100 тиков, сетевой пакет клиенту; синусоидальное покачивание камеры и слабый боковой дрейф при высоком опьянении.
- Клиентская настройка `cameraSway=0.0..1.0` в конфигурации, по умолчанию 0.7.
- Бутылки ставятся на верхнюю сторону твёрдых блоков и поднимаются ПКМ, NBT содержимого сохраняется.
- Винная стойка на 6 бутылок с NBT, отображением бутылок через BlockEntityRenderer, выдачей и сохранением при разрушении.
- Бочка и квеври: загрузка виноградного сусла (1–12 порций), брожение 2400 тиков, выдача вина за пустую бутылку. Бочка — красное, квеври — янтарное.
- Крафты на основные блоки, оружие, броню, материалы; RU/EN локализация, ресурсы 16×16.

## Чего ещё нет / пределы v0.1
- **Нет протестированного `.jar` и прогона `gradle build`,** возможны ошибки API и игровые баги. Это не релиз.
- Нет полноценной баллистики снарядов (выстрел — луч), оружейной анимации рук, литейного производства свинца, полноценной винной экономики и десятков отдельных сортов.
- Ручной наруч пока декоративный, щит наследует vanilla-механику; броня использует обычную геометрию брони игрока.
- Установленные бутылки отображаются отдельным рендерером по спрайту своего сорта (не полноценная уникальная 3D-геометрия); тип хранится в NBT.
- Рецепт сусла использует сладкие ягоды как временную замену винограду; это игровая условность.
- Боковое отклонение движения может требовать доработки для клиентского предсказания на сервере.
- Точные исторические названия, баллистика и ABV требуют источниковедческой проверки; значения опьянения — игровой баланс, а не медицинская модель.

## Сборка на ПК (Java 17 + интернет)
1. Для автоматической сборки без Java на своём ПК используй `.github/workflows/build.yml` (GitHub Actions) — инструкция в `HOW_TO_GET_JAR_RU.md`.
2. Для локальной сборки с установленным JDK 17 запусти `build-windows.bat` или `build-linux-macos.sh`. Скрипт скачает Gradle при необходимости, после чего Gradle получит зависимости Forge.
3. Если сборка прошла, файл `build/libs/eac16-0.1.0.jar` скопируй в `mods/` Forge 1.20.1.
4. Проверь одиночную игру и выделенный сервер (в обоих случаях один и тот же мод).

## Проверка функций
1. Творческая вкладка «Восточная Европа и Кавказ | XVI век»; наличие всех предметов.
2. Установить стойку, положить 1–6 напитков ПКМ, снять пустой рукой, сломать и проверить выпадение.
3. Взять напиток, ПКМ по верхней стороне блока (установить), ПКМ по бутылке (забрать), ПКМ в воздух (выпить).
4. Крафтить виноградное сусло из стеклянной бутылки, сладких ягод и сахара; загрузить в бочку, дождаться готовности, извлечь в пустую бутылку.
5. Получить фитильное ружьё, порох и железную пулю; удерживать ПКМ для зарядки, снова ПКМ для стрельбы.
6. Выпить несколько порций и оценить плавность наклона камеры; в конфиге установить cameraSway=0 и проверить отключение визуального эффекта.

## Реальное положение дел
Этот проект — большой шаг дальше набора текстур: в нём есть Java-системы, игровые данные и визуальные ресурсы. Но без скачивания Forge MDK и успешной компиляции его нельзя считать полностью готовым Forge-модом. Разумно сначала собрать и отладить v0.1, затем расширять контент.

## Проверка статических ресурсов
Запусти `python tools/check_resources.py`: проверяются JSON, PNG, связи моделей с текстурами, разрешение 16×16/64×32 и рецепты. Этот тест не компилирует Java и не проверяет взаимодействия в мире.
